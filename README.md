# 🛍️ Production Capstone Project

## 📌 About the Project
Production Capstone Project is a responsive product store developed using HTML5, CSS3, and JavaScript.

## ✨ Features
- 🔐 Login simulation
- 🛍️ Interactive product catalog
- 🔎 Product search
- 🗂️ Category filtering
- ➕ Add products
- ✏️ Edit products
- 🗑️ Delete products
- 🛒 Shopping cart
- 💰 Automatic cart total
- 💾 Data persistence using localStorage
- 📱 Responsive mobile and desktop layout
- ⌨️ Keyboard focus indicators

## 🧰 Technologies Used
- HTML5
- CSS3
- JavaScript
- Browser localStorage
- GitHub

## 📂 Project Structure
production-capstone-project/
├── index.html
├── style.css
├── script.js
└── README.md

## 🚀 How to Run
1. Download or clone this repository.
2. Open index.html in a web browser.
3. Search products and filter by category.
4. Add, edit, or delete products.
5. Add products to the cart.
6. Refresh the page to check saved data.

## 🔐 Security Note
This project uses a simulated login. It does not provide real authentication or secure user accounts. Do not enter real passwords or sensitive information.

## 💾 Data Storage
Product information and shopping cart data are stored in the browser's localStorage.

## 🎯 Project Goal
To demonstrate interactive web development, CRUD operations, responsive design, and browser-side data persistence.

## 👨‍💻 Conclusion
This project demonstrates a simple, interactive online store using core web technologies.
