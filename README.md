🛍️ ShopSmart – Production Capstone Project

🌟 Project Overview

ShopSmart is a responsive online product store developed using HTML5, CSS3, and JavaScript.

The application allows users to explore products, search and filter items, manage product details, and interact with a shopping cart.

This project demonstrates front-end development, DOM manipulation, CRUD operations, responsive design, and browser-based data storage.

🎯 Objectives

- Develop a responsive product store.
- Implement product search and category filtering.
- Support adding, editing, and deleting products.
- Create a shopping cart with quantity controls.
- Store product and cart data using localStorage.
- Demonstrate a simple login simulation.
- Improve usability with accessible labels and keyboard focus.

✨ Features

🔐 Demo Login

Users can enter a username to see a simulated login message. This is not real authentication.

🛍️ Product Catalog

Displays products with names, descriptions, prices, and categories.

🔎 Search and Filtering

Search products by name or description and filter by category.

➕ Product Management

Add new products, edit existing products, and delete products.

🛒 Shopping Cart

Add products, update quantities, remove items by reducing their quantity to zero, and calculate the total price.

💾 Local Storage

Products and cart contents are saved in the browser using localStorage.

📱 Responsive Design

The layout adapts to desktop, tablet, and mobile screens.

💳 Demo Checkout

Demonstrates the checkout flow without processing real payments.

🚀 How to Run

1. Download or clone this repository.
2. Keep all three application files in the same folder.
3. Open "index.html" in a modern web browser.
4. Search for products and test the category filters.
5. Add products to the cart.
6. Add, edit, and delete products using the product management form.
7. Refresh the page to test localStorage persistence.

🔒 Security and Limitations

This project is a front-end demonstration.

- Login is simulated and does not verify user credentials.
- No real payment processing is implemented.
- localStorage is browser-based and is not a secure database.
- Product changes are local to the browser and are not shared between users.
- A production application would require a secure backend, server-side validation, authentication, authorization, and a database.
