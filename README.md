# 🛍️ Production Capstone Project

## 📌 About the Project
Production Capstone Project is a responsive product store developed using HTML5, CSS3, and JavaScript.

It provides an interactive shopping experience with product management, search, category filtering, and a shopping cart.

## 🌐 Live Demo
Visit the deployed application:

https://production-capstone-project.vercel.app/

## ✨ Features
- 🔐 Login simulation
- 🛍️ Interactive product catalog
- 🔎 Product search
- 🗂️ Category filtering
- ➕ Add new products
- ✏️ Edit existing products
- 🗑️ Delete products
- 🛒 Shopping cart functionality
- 💰 Automatic cart total calculation
- 💾 Data persistence using localStorage
- 📱 Responsive mobile and desktop layout
- ⌨️ Keyboard focus indicators

## 🧰 Technologies Used

## 🚀 How to Run Locally

1. Clone or download this repository.
2. Open the project folder.
3. Open `index.html` in a web browser.
4. Search for products or filter them by category.
5. Add, edit, or delete products.
6. Add products to the shopping cart.
7. Refresh the page to check saved data.

## 💾 Data Storage
Product information and shopping cart data are stored
in the browser's localStorage.

Saved data can persist after refreshing the page
in the same browser.

## 🔐 Security Note
This project uses a simulated login and does not
provide real authentication or secure user accounts.

Do not enter real passwords or sensitive information.

## 📱 Responsive Design
The application is designed to work on mobile phones
